# MineAndCraft

Воксельная sandbox-игра в духе Minecraft на Java + LWJGL 3. Мир генерируется бесконечно чанками по мере движения игрока.

## Требования

- **JDK 21+** (в проекте настроен Java 25)
- **Maven 3.9+**
- **Windows** (нативные библиотеки LWJGL подключены для Windows)

## Быстрый старт

```bash
mvn compile exec:java
```

Или в IntelliJ IDEA: запустите `com.mineandcraft.Main`.

## Управление

| Действие | Клавиша |
|----------|---------|
| Движение | `W` `A` `S` `D` |
| Прыжок | `Space` |
| Спринт | `Ctrl` |
| Ломать блок | Зажать **ЛКМ** |
| Ставить блок | **ПКМ** |
| Слот хотбара | `1`–`9` или **колёсико мыши** |
| Пауза / меню | `Escape` |

## Меню и настройки

Нажмите **Escape**, чтобы открыть меню паузы:

- **Продолжить** — вернуться в игру
- **Настройки** — чувствительность мыши, FOV, дальность прорисовки, скорость движения, туман, VSync, отладочный оверлей
- **Выйти** — закрыть игру

Настройки сохраняются в `%USERPROFILE%\.mineandcraft\settings.properties` и подхватываются при следующем запуске.

## Структура проекта

```
src/main/java/com/mineandcraft/
├── Main.java                 # Точка входа
├── config/                   # Игровые настройки и сохранение
├── engine/                   # Игровой цикл, окно, камера, рейкаст
│   └── physics/              # Коллизии игрока
├── graphics/                 # Шейдеры, текстуры, HUD, UI-отрисовка
├── player/                   # Хотбар и управление инвентарём
├── ui/                       # Меню паузы и экран настроек
└── world/                    # Блоки, генерация мира, чанки, рендер

src/main/resources/
└── textures/                 # Текстуры (grass.png и др.)
```

## Сборка JAR

```bash
mvn package
```

## Технологии

- [LWJGL 3](https://www.lwjgl.org/) — окно, OpenGL, загрузка изображений
- [JOML](https://github.com/JOML-CI/JOML) — математика (матрицы, векторы)
- OpenGL 3.3 Core — рендер мира и интерфейса

## Лицензия

Учебный проект. Не является копией Minecraft и не использует его ассеты.
